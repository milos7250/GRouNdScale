\section{Overview}
This report summarises 18 completed training runs of the causal GAN pipeline with increasingly higher highly variable gene (HVG) counts, from 991 to 17,789 genes. Every run uses the same architecture and training configuration (20 steps for the causal controller, then 20 steps for the main causal GAN); only the HVG count selected during preprocessing differs.

Causal-graph statistics are recomputed from the saved \texttt{causal\_graph.pkl} of each run, because preprocessing and GRN inference are skipped when the graph already exists and the logs therefore contain no graph summary. The run requesting 18{,}000 HVGs resolved to 17,789 genes and is labelled by that gene count.

All runs completed without CUDA out-of-memory errors. The largest run peaked at 19,489\,MiB, against a GPU capacity of 81,920\,MiB.

\section{Scaling Relations}
Ordinary least-squares fits over all runs, with $x$ the number of highly variable genes,
give the causal-generator requirements
\begin{equation}
\widehat{M}_{\mathrm{gen}}(x) = 0.7126\,x + 6778.8\ \mathrm{MiB},\qquad R^2 = 0.9997
\end{equation}
\begin{equation}
\widehat{t}_{\mathrm{gen}}(x) = 0.06341\,x + 13.93\ \mathrm{ms/step},\qquad R^2 = 0.9961
\end{equation}
The memory fit uses the peak memory of the generator training window and the time fit uses the second final-step log line. The relations describe the measured range only.

\subsection{Gene Count versus Target-Gene Count}
Fitting against the number of target genes instead of highly variable genes gives $R^2 = 0.9998$ for memory and $R^2 = 0.9968$ for step time, compared with $R^2 = 0.9997$ and $R^2 = 0.9961$ for the gene-count fits. The two predictors are strongly correlated, so the differences are small, but the target-gene form is the better description of the underlying model size:
\begin{equation}
\widehat{M}_{\mathrm{gen}}(y) = 0.7670\,y + 6805.3\ \mathrm{MiB},\qquad R^2 = 0.9998
\end{equation}
\begin{equation}
\widehat{t}_{\mathrm{gen}}(y) = 0.06827\,y + 16.12\ \mathrm{ms/step},\qquad R^2 = 0.9968
\end{equation}
where $y$ denotes the number of target genes in the causal graph.

\section{Notes}
\begin{itemize}
\item All runs share the architecture: latent dim 128, generator layers 256--512--1024, critic layers 1024--512--256, labeler layers 2000--2000--2000, batch size 1024 and 20 steps per phase.
\item The controller phase is trained first with batch size 128 and the main causal GAN second with batch size 1024; generator training dominates the memory requirement.
\item Memory values are in MiB as reported by \texttt{nvidia-smi}.
\end{itemize}
