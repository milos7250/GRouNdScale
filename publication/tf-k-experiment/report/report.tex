\section{Overview}
This report analyses the 15 completed runs of the publication top-$k$ experiment. The GRN parameter $k$ is the number of top-ranked transcription factors retained per gene (TFs per gene), and $k$ is the independent variable throughout the scaling analysis, replacing imposed-edge count. Imposed edges are shown only as a descriptive column in Table~\ref{tab:grn}.
Logs are taken from Slurm job \texttt{35270928}, which matches the current \texttt{results/} directory. The older job \texttt{34606270} and \texttt{results-old/} are excluded.
\paragraph{Observed dimensions.} The HVG and target-gene counts are constant across runs, but the TF and gene counts are not perfectly fixed: the $k=1$ run has 194 TFs and 2,997 genes, while all other runs have 197 TFs and 3,000 genes. This is reported as observed; the Notes section includes a sensitivity check that excludes $k=1$.

\section{Fits in $k$}\label{sec:fits}
Let $k$ denote the number of TFs per gene. Ordinary least-squares fits over all 15 runs give:
\begin{align}
\widehat{P}_{\mathrm{gen}}(k) &= 5.045\times10^{5}\,k - 1.065\times10^{6}\ \mathrm{parameters},\quad R^2=0.9645, \\
\widehat{M}_{\mathrm{gen}}(k) &= 87.95\,k + 7548\ \mathrm{MiB},\quad R^2=0.9861, \\
\widehat{t}_{\mathrm{gen}}(k) &= 12.47\,k + 9.857\ \mathrm{ms/step},\quad R^2=0.9629.
\end{align}
Quadratic fits, which capture the curvature visible in the data, are:
\begin{align}
\widehat{P}_{\mathrm{gen},2}(k) &= 2.523\times10^{4}\,k^2 + 1.009\times10^{5}\,k + 7.849\times10^{4}\ \mathrm{parameters},\quad R^2=1.0000, \\
\widehat{M}_{\mathrm{gen},2}(k) &= 1.179\,k^2 + 69.09\,k + 7602\ \mathrm{MiB},\quad R^2=0.9887, \\
\widehat{t}_{\mathrm{gen},2}(k) &= 0.5815\,k^2 + 3.163\,k + 36.22\ \mathrm{ms/step},\quad R^2=0.9938.
\end{align}

\section{Notes}
\begin{itemize}
\item Sensitivity to the $k=1$ point (which has different TF and gene counts): excluding it, the linear/quadratic $R^2$ are 0.9718/1.0000 for parameters, 0.9829/0.9887 for peak memory, and 0.9697/0.9930 for step time.
\item Runs with an out-of-memory error: 0 of 15.
\item The linear parameter fit crosses zero at $k\approx2.1$, so it predicts a negative generator parameter count below that value; the quadratic fit reproduces the measured counts and should be used at small $k$.
\item The TF/target ratio is essentially constant (6.92\% at $k=1$; 7.03\% for $k\ge2$), because the target count is fixed. A ratio-based figure would therefore carry no information and is omitted; the scaling is attributed to $k$.
\item The controller peak memory is flat across $k$ (from 6,159 to 6,231 MiB), as expected because the controller does not depend on $k$. This supports attributing the generator's growth to $k$ rather than to a phase-window artefact.
\item GPU capacity is 81,920 MiB; the largest generator peak is 8,869 MiB at $k=14$.
\end{itemize}
