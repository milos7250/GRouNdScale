\section{Purpose}

This report derives how the causal-generator parameter count changes when the number of
transcription factors, target genes, top-$k$ regulators, depth, width, or noise variables is
varied. It also gives the equivalent expression in terms of the number of imposed edges.

The analysis describes the causal generator implemented in
\texttt{src/networks/masked\_causal\_generator.py}. It assumes that every target gene has exactly
$k$ selected regulators, so that the number of imposed edges is
\begin{equation}
E = kG,
\end{equation}
where $G$ is the number of target genes.

\section{Causal-Graph Generator}

For target gene $i$, let $r_i$ be its number of regulators. Under the fixed-top-$k$ assumption,
$r_i=k$ and every target block has width $h=w(k+n)$.

The sparse generator contains three types of masked linear layers:

\begin{align}
P_{\mathrm{input}} &= G\,w(k+n)^2,\\
P_{\mathrm{hidden}} &= dG\,w^2(k+n)^2,\\
P_{\mathrm{output}} &= Gw(k+n).
\end{align}

Including SparseLinear biases and BatchNorm affine parameters gives the causal-graph-specific
generator count
\begin{equation}
\boxed{
P_{\mathrm{graph}}(F,G,k,d,w,n)
=G\left[
w(k+n)^2
{}+d w^2(k+n)^2
{}+(3d+4)w(k+n)
{}+1
\right].
}
\end{equation}

The TF count $F$ does not appear in this term because SparseLinear stores parameters only for
the selected regulator connections. $F$ controls the available TF feature space and constrains
$k$, but not the number of selected connections when $k$ is fixed.

\section{Causal-Controller Contribution}

The causal controller is a dense MLP whose final layer outputs all $N=F+G$ genes. Let its latent
dimension be $z$, and let its hidden widths be $a_1,\ldots,a_m$, with $a_0=z$. The trainable
controller parameter count is
\begin{equation}
P_{\mathrm{CC}}(F,G)
=\sum_{j=1}^{m}\left[(a_{j-1}+1)a_j+2a_j\right]
+(a_m+1)(F+G).
\end{equation}

The full generator count, when the pretrained causal controller is included in the generator
state dictionary, is therefore
\begin{equation}
\boxed{
P_{\mathrm{gen}}
=P_{\mathrm{CC}}(F,G)+P_{\mathrm{graph}}(F,G,k,d,w,n).
}
\end{equation}

If the controller is counted separately, omit $P_{\mathrm{CC}}$.

\section{Partial Scaling Functions}

Each expression below varies one variable while all other variables remain fixed.

\subsection{Transcription Factors}

\begin{equation}
\boxed{
P(F)=C_0+L(F+G)+K
}
\end{equation}

where $L=a_m+1$, $C_0$ contains controller terms independent of $F$ and $G$, and $K$ is the
causal-graph contribution. Thus, parameter count is linear in $F$.

\subsection{Target Genes}

\begin{equation}
\boxed{
P(G)=C_0+LF
{}+G\left[L+w(k+n)^2+d w^2(k+n)^2+(3d+4)w(k+n)+1\right].
}
\end{equation}

With $k,d,w,n$ fixed, parameter count is linear in $G$.

\subsection{Top-$k$}

\begin{equation}
\boxed{
P(k)=C_0+L(F+G)
{}+G\left[(w+dw^2)(k+n)^2+(3d+4)w(k+n)+1\right].
}
\end{equation}

Therefore, parameter count is quadratic in $k$.

\subsection{Depth}

\begin{equation}
\boxed{
P(d)=C_0+L(F+G)+G\left[
w(k+n)^2
{}+d\left(w^2(k+n)^2+3w(k+n)\right)
{}+4w(k+n)+1
\right].
}
\end{equation}

Parameter count is linear in $d$.

\subsection{Width}

\begin{equation}
\boxed{
P(w)=C_0+L(F+G)+G\left[
d(k+n)^2w^2
{}+\left((k+n)^2+(3d+4)(k+n)\right)w
{}+1
\right].
}
\end{equation}

Parameter count is quadratic in $w$ because the fully connected hidden blocks scale with the
square of each block's width.

\subsection{Noise Per Gene}

\begin{equation}
\boxed{
P(n)=C_0+L(F+G)+G\left[(w+dw^2)(k+n)^2+(3d+4)w(k+n)+1\right].
}
\end{equation}

Parameter count is quadratic in $n$.

\subsection{Imposed Edges}

Using $k=E/G$ gives
\begin{equation}
\boxed{
P(E)=C_0+L(F+G)+G\left[
 (w+dw^2)\left(\frac{E}{G}+n\right)^2
 +(3d+4)w\left(\frac{E}{G}+n\right)+1
\right].
}
\end{equation}

For fixed $F$, $G$, $d$, $w$, and $n$:
\begin{equation}
\boxed{P(E)=AE^2+BE+C.}
\end{equation}

The leading coefficient is proportional to $(w+dw^2)/G$. This is the analytical reason that
the top-$k$ experiment exhibits quadratic generator-parameter scaling with imposed edges.

\section{Interpretation}

The quadratic term is caused by the block-diagonal, fully connected hidden masks inside each
target-gene generator. For target $i$, the dominant contribution is proportional to
$(r_i+n)^2$. Under uniform top-$k$ selection, $r_i=k$ and $E=kG$, yielding the quadratic
dependence on $E$.

For arbitrary causal graphs, total edge count alone is not sufficient. The more general scaling is
\begin{equation}
P_{\mathrm{graph}}\ \propto\ \sum_{i=1}^{G}(r_i+n)^2.
\end{equation}

Two graphs with the same $E$ can therefore have different parameter counts if their regulator
degrees are distributed differently. A highly concentrated regulator distribution produces a
larger sum of squares than a uniform distribution.
