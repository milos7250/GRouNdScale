\section{Purpose}

This report derives the causal-generator parameter-count scaling for the original upstream
implementation in \texttt{/mnt/shared/scratch/mmicik/private/Geneformer/simulation/upstream/GRouNdGAN}.
It is intentionally separate from the corresponding analysis for the \texttt{dedup} implementation.

Assume every target gene has exactly $k$ regulators, so the imposed-edge count is
\begin{equation}
E=kG,
\end{equation}
where $G$ is the number of target genes.

The upstream implementation uses dense tensors whose weights are masked at forward and backward
time. Therefore, trainable-parameter counts and checkpoint/state-dict tensor counts are different.

\section{Original Masked Generator}

In the upstream code, \texttt{MaskedLinear} creates a dense weight tensor with shape
\texttt{(output\_features, input\_features)} and separately stores the mask. The mask zeros
weights and gradients but does not make the weight tensor sparse.

The three masked layers have shapes:
\begin{align}
\text{input layer:} &\quad X \times H,\\
\text{hidden layer:} &\quad H \times H,\\
\text{output layer:} &\quad H \times G.
\end{align}

There is one input layer, $d$ hidden layers, and one output layer.

\subsection{Trainable Parameters}

Counting dense weights, biases, and BatchNorm affine parameters, the causal-graph-specific
generator has
\begin{equation}
\boxed{
P_{\mathrm{graph,train}}
=HX+dH^2+HG+(3d+3)H+G.
}
\end{equation}

The terms are respectively dense weights, masked-layer biases, and BatchNorm affine parameters.

\subsection{Checkpoint/State-Dict Tensor Count}

The upstream mask is an \texttt{nn.Parameter} with \texttt{requires\_grad=False}, so it is present
in the state dictionary. BatchNorm also stores running mean, running variance, and a batch counter.
Counting those tensors gives
\begin{equation}
\boxed{
P_{\mathrm{graph,state}}
=2HX+2dH^2+2HG+5(d+1)H+(d+1)+G.
}
\end{equation}

This is the appropriate expression when comparing against a checkpoint-inspection result that
counts every tensor in the state dictionary rather than only trainable tensors.

\section{Causal Controller}

Let the causal-controller latent dimension be $z$, its hidden widths be
$a_1,\ldots,a_m$, and $a_0=z$. Its output dimension is $N=F+G$.

The trainable controller count is
\begin{equation}
P_{\mathrm{CC,train}}
=\sum_{j=1}^{m}\left[(a_{j-1}+1)a_j+2a_j\right]
+(a_m+1)(F+G).
\end{equation}

For state-dict counting, each hidden BatchNorm additionally contributes its running statistics and
counter:
\begin{equation}
P_{\mathrm{CC,state}}
=\sum_{j=1}^{m}\left[(a_{j-1}+1)a_j+4a_j+1\right]
+(a_m+1)(F+G).
\end{equation}

If the generator state dictionary includes the pretrained controller, the full original-generator
count is
\begin{equation}
\boxed{
P_{\mathrm{gen,state}}
=P_{\mathrm{CC,state}}+P_{\mathrm{graph,state}}.
}
\end{equation}

For trainable parameters only, replace both state terms with their trainable counterparts.

\section{Partial Scaling Functions}

The following expressions hold with all variables other than the named variable fixed.

\subsection{TF Count $F$}

Because $X=F+nG$ and the controller output is $F+G$:
\begin{equation}
\boxed{
P_{\mathrm{graph,state}}(F)
=2H F + C_F,
}
\end{equation}
where $C_F$ is independent of $F$. Thus, the upstream state-dict count is linear in $F$.

\subsection{Target-Gene Count $G$}

With $F,k,d,w,n$ fixed, $H=Gw(k+n)$ and $X=F+nG$. Therefore:
\begin{equation}
\boxed{
P_{\mathrm{graph,state}}(G)
=2d w^2(k+n)^2G^2
+2w(k+n)(F+nG)G
+2w(k+n)G^2
+5(d+1)w(k+n)G
+(d+1)+G.
}
\end{equation}

Unlike the sparse implementation, the original dense-mask implementation is quadratic in $G$.

\subsection{Top-$k$}

With $F,G,d,w,n$ fixed and $q=k+n$:
\begin{equation}
\boxed{
P_{\mathrm{graph,state}}(k)
=2G^2dw^2(k+n)^2
+2Gw(k+n)(F+nG+G)
+5(d+1)Gw(k+n)
+(d+1)+G.
}
\end{equation}

Thus, the original implementation is quadratic in $k$.

\subsection{Depth $d$}

With $F,G,k,w,n$ fixed:
\begin{equation}
\boxed{
P_{\mathrm{graph,state}}(d)
=2G^2w^2(k+n)^2d
+5Gw(k+n)d
+C_d,
}
\end{equation}
where $C_d$ is independent of $d$. Depth is linear.

\subsection{Width $w$}

With $F,G,k,d,n$ fixed:
\begin{equation}
\boxed{
P_{\mathrm{graph,state}}(w)
=2dG^2(k+n)^2w^2
+\left[2G(k+n)(F+nG+G)+5(d+1)G(k+n)\right]w
+C_w.
}
\end{equation}

Width is quadratic because the dense hidden matrices scale as $H^2$.

\subsection{Noise Per Gene $n$}

With $F,G,k,d,w$ fixed, both $H=wG(k+n)$ and $X=F+nG$ vary with $n$:
\begin{equation}
\boxed{
P_{\mathrm{graph,state}}(n)
=2dG^2w^2(k+n)^2
+2Gw(k+n)(F+nG+G)
+5(d+1)Gw(k+n)
+(d+1)+G.
}
\end{equation}

Noise count is quadratic.

\subsection{Imposed Edges $E$}

Substituting $k=E/G$ gives $H=w(E+nG)$ and
\begin{equation}
\boxed{
\begin{aligned}
P_{\mathrm{graph,state}}(E)={}&2d w^2(E+nG)^2\\
&+2w(E+nG)(F+nG+G)\\
&+5(d+1)w(E+nG)+(d+1)+G.
\end{aligned}
}
\end{equation}

For fixed $F,G,d,w,n$:
\begin{equation}
\boxed{P_{\mathrm{graph,state}}(E)=AE^2+BE+C.}
\end{equation}

The quadratic coefficient is $2dw^2$ for the state-dict count. For trainable parameters it is
$dw^2$ because the fixed mask tensors are excluded.

\section{Significant Differences from \texttt{dedup}}

\begin{table}[H]
\centering
\caption{Implementation differences that change the scaling equations.}
\begin{tabular}{p{0.28\textwidth}p{0.31\textwidth}p{0.31\textwidth}}
\toprule
Feature & Original upstream implementation & \texttt{dedup} implementation \\
\midrule
Masked layer & Dense \texttt{MaskedLinear} weight matrices; masks zero weights and gradients. & Connectivity-based \texttt{SparseLinear}; only selected connections receive weight parameters. \\
TF dependence & The input matrix has shape $(F+nG)\times H$, so $F$ directly affects parameter count. & TF count mostly affects connectivity indices; it does not multiply the stored sparse weights for fixed $k$. \\
State-dict masks & Masks are \texttt{nn.Parameter(requires\_grad=False)} and are saved in checkpoints. & Connectivity is stored as index data; dense mask tensors are not stored as model parameters. \\
Generator contents & \texttt{CausalGenerator} creates an internal \texttt{\_labeler}. & The deduplicated causal-generator module does not create that internal labeler. \\
Mask construction & Dense $H\times H$ masks are materialized. & Masks are constructed as sparse CSR matrices and converted to connectivity indices. \\
Implication & Dense hidden matrices make parameter/state-dict scaling larger and more explicitly dependent on $F$, $G$, and $H^2$. & Sparse parameter scaling follows the number of nonzero connections, with a different coefficient and weaker TF dependence. \\
\bottomrule
\end{tabular}
\end{table}

The same logical top-$k$ graph can therefore produce substantially different parameter counts in
the two implementations. The upstream equations must not be applied to \texttt{dedup} checkpoint
counts, and vice versa.
