training.helpers.set_learning_rate_scheduler(optimizer: Optimizer, alpha_0: float, alpha_final: float, max_steps: int, decay_type: str = 'cosine', warmup_percent: float = 0.02, holding_percent: float = 0.6) → LRScheduler[source]#

Set up a warmup, holding, and decay learning rate schedule.

Parameters:

  • optimizer (Optimizer) – Optimizer for which to create a learning rate scheduler.

  • alpha_0 (float) – Initial learning rate.

  • alpha_final (float) – Final learning rate.

  • max_steps (int) – Total number of training steps. When current_step=max_steps, alpha_final will be set as the learning rate.

  • decay_type (str, default: 'cosine') – Decay curve to use: linear, cosine, or exponential.

  • warmup_percent (float, default: 0.02) – Percentage of total steps to use for learning rate warmup (default 0.02).

  • holding_percent (float, default: 0.6) – Percentage of total steps at which the holding phase ends, including warmup (default 0.60).

Returns:

Learning rate scheduler. Call the step() function on this scheduler in the training loop.

Return type:

LRScheduler
