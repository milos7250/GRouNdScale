sc_dataset.get_loader(file_path: Path, batch_size: int | None = None, shuffle: bool = False, drop_last: bool = False, deterministic: bool | None = None) → SCDataLoader[source]#

Provides an IterableLoader over a scRNA-seq Dataset read from given h5ad file.

Parameters:

  • file_path (Path) – Path to the h5ad file.

  • batch_size (int | None, default: None) – Training batch size. If not specified, the entire dataset is returned at each load. Default is None.

  • shuffle (bool, default: False) – Whether to shuffle the data in the loader. Default is False.

  • drop_last (bool, default: False) – Whether to drop the last incomplete batch. Default is False.

  • deterministic (bool | None, default: None) – Whether to use deterministic data loading. Default is based on calling torch.are_deterministic_algorithms_enabled().

Returns:

Iterable data loader over the dataset.

Return type:

SCDataLoader
